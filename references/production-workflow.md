# 制作流程

按当前任务推进，继承有效确认和已有材料。页面顺序由评选标准、内容主线和证据决定。

## 1. 阅读材料并明确约束

有 PPT 时阅读全稿并核看实际显示，识别未改页、内容页、过渡页、动画状态页及需要保留的图文与动效。

没有 PPT 时从素材中提取经历、数据、成果和证据。只有模板时先明确固定、借鉴和可变范围，再提取必要的视觉约束。集中确认评选对象、评价标准、限时和必须保留的信息；材料已回答的事项不再追问。对象可以是个人或各类集体，沿用其真实称谓和评价维度。

沿用已知的画幅、目标展示软件与交付要求，只询问影响设计或制作的缺口。关键数字、奖项、贡献和证据保留可追溯的材料位置，便于核对。

## 2. 组织论述与页面任务

围绕评选目标，安排核心优势、具体行动、贡献、结果和证据。内容不足时查找遗漏素材或询问关键缺口，不补造经历与数据。

在已有方案中简短记录每页的“结论—信息关系—整页框架—图文证据位置—导航位置—跨页关联”。说明主轴、层面或中心怎样组织本页，以及主要文字、数字与证据怎样对应；无需另建重复的规格体系。材料多时突出代表成果并组织次级细节；内容少时调整页面任务，不靠装饰填满。

拟定全稿导航标签，名称覆盖该部分实际内容，保持概括层级、字数、句式和动宾结构协调。当前页标题说明眼前内容，导航说明整稿位置。

重写文案、调整章节、增删或拆并页面时，先呈现具体变更与理由，确认后修改。

## 3. 选择视觉方向与整页布局

从参评对象、主题、机构气质和素材条件确定视觉方向。无明确方向时提供 2—3 个实质不同的方案，比较相同主要内容；明确只要一个预览时选择一个方向并说明。

新建或大改正文页时，先按真实关系查阅[整页布局方法](page-layouts.md)，判断适合层级、阶段、循环、中心辐射、并行支撑、对照或数据组织等哪种框架。决定框架如何分配整张正文区，再安排解释、照片、数据和证据；局部关系可以采用另一种构件。主图或成果证据需要较大面积时，以它为视觉中心，用周边文字和引导线补足关系。

按本页表达问题查阅[图解方法库](pattern-library.md)：在同一条目里看示例、适用内容和借鉴边界，再决定如何迁移。只选相关片段，不沿用来源稿的页序或固定布局；未列入参考范围的页面不作标准。必要时补充独立参考。

参考截图先判断完整度，分清 PPT 本体与 App/宣传外壳。对选中的图解，在已有构图方案内说清节点、连接、分组、阅读顺序、证据位置及可编辑对象；不把“像这张图”作为唯一制作指令。局部和缩略图不支持的细节保持开放，仅在任务确需精确复现时补充清晰来源。

按选中方法已有的相关资源，查看正文区大图、结构 PNG 或 SVG。大图用于理解整页空间，SVG 用于理解节点与连接；资源无需逐条成对齐全。按本页内容重组，不直接继承示例文案、颜色与节点数。

统一外框、导航、字体角色和图注等全稿语言，正文构图随关系、主图和证据量变化。检查相邻页的主构图是否有节奏；不为追求变化强换结构，也不把所有材料装入同一组卡片。

## 4. 设计预览并确认

新增、大改或从零制作时，可用生图能力生成样页。选取有代表性的内容检验字体、数字强调、图文比例、证据面积和信息密度；不预设所有任务都需要同样数量或类型的样页。

生图是风格与构图预览，用于判断视觉气质、信息层级和密度，不是逐字逐线的制作底稿。端点未贴合节点、局部字形等不影响方向选择的偏差，可在后续 PPT 技能或脚本绘制时修正；无需仅为此重新生图。内容与关系依原材料、文字方案确定；若偏差妨碍理解或选择方向，先澄清方案，必要时调整预览。

引用示例时明确每张参考的作用及借鉴范围，在提示中写清本页结论、主关系、整页框架、阅读路径、字体角色、配色、边界、导航和证据安排。用于探索的新方向可采用不同构图与图形语言；不把生成的上一张图当作唯一质量基准。真实材料不足的预览用待填字段或明确的示意素材，正式制作仍依照原始文字、数据与图片。

正式制作前给出全部待制或待改页面的缩略图总览，并附关键页大图。总览体现拟采用的主要内容、稳定导航、不同构图及证据安排，示意与待填部分标清；不要求细节达到成品精度，也不能仅列标题或空白框。

共享对象运动、胶片滑动或导航高亮转移，用起止状态或简洁说明表达。确认内容方案和总方向后执行；同一批已确认事项不重复询问。

## 5. 制作可编辑成品

调用现有 PPT 制作技能并遵循其匹配流程。文字、数字、表格优先可编辑，照片与证据分别可替换，复杂背景按需要图片化。

在已有页面方案或执行技能的制作规格中交接：当前基准文件与修改范围、确认后的内容和原始证据、画幅与目标软件、模板固定项、导航、字体角色与本稿视觉参数、图文位置及共享对象/动效要求。继承有效确认，只处理新增缺口，不另建重复规格或重新询问已确定事项。

根据原材料与页面方案，用原生对象或合适脚本落实真实文字、数据、节点及连接。复杂图解在实际构建时核对起止节点、方向与条件，修正生图中的示意偏差；不要求逐像素复刻预览。

保留未涉及页面的原生内容和有效动画。修改关联内容时同步前后页与隐藏状态；恢复其他版本的局部内容时同步当前视觉体系。接收人工修改版后，以该版继续。

共享照片、图注、文字和组件保留对象对应，明确固定项与移动项，完成已确认的连续展示。实际字体与内容需要的局部调整自主处理，明显改变已确认方向时重新展示。

## 6. 根据问题调整所属层级

| 问题 | 优先调整 |
|---|---|
| 信息单薄 | 补充真实行动、数据与证据，或重设页面任务 |
| 页面过载 | 提高分组与层级，必要时提出拆页或分步展示 |
| 排版雷同 | 改变主图、信息关系、分区与证据组织 |
| 证书不整齐 | 修正比例、裁切、尺寸、对齐与间距 |
| 报道或报告过小 | 重新分配展示面积，必要时替换次要照片 |
| 文字空散、对齐失衡 | 调整同层级对齐和模块关系，比较信息再考虑表格 |
| 修改破坏已认可部分 | 恢复指定优点，并与当前体系协调 |

解决实际问题，不将局部意见扩大为无关的全稿重做。

## 7. 检查并交付

核看全稿节奏、关键页大图与涉及的放映状态。检查事实口径、字体、溢出、裁切、证据可读性、外框层次、导航高亮、图解语义、图注与共享对象衔接。核对本页主关系是否贯穿图文安排，以及整页框架是否帮助突出结论、读懂证据。

对照已确认的视觉方向与页面方案，核看成品实际渲染中的构图、字体层级、图文比例和证据面积。适配真实素材与字体所需的局部调整可自主处理；明显改变已确认方向时说明具体差异并重新展示。

核对核心文字、数字、表格与图表是否可编辑，照片与证据能否替换，需连续运动的对象是否保持对应；不能仅据 SVG 存在或静态外观相似认定通过。

交付可编辑 PPTX 和静态预览，讲稿按需提供。保留原文件，报告实际检查结果与影响使用的未解决问题。
